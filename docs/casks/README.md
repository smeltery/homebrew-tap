# Casks

Binary packages installed with `--cask`.

| Cask | Description |
| --- | --- |
| [aptscout](aptscout/README.md) | Apartment availability tracker CLI |
| [awsw](awsw/README.md) | Switch between AWS SSO accounts and EKS contexts |
| [bellows](bellows/README.md) | Run GitHub Actions locally before you push |
| [distill](distill/README.md) | AI-powered knowledge compactor for agents |
| [gh-identity](gh-identity/README.md) | Multi-account GitHub identity management |
| [glimpse](glimpse/README.md) | GitHub-style git diff viewer CLI |
| [prr](prr/README.md) | AI-powered PR code review CLI |
