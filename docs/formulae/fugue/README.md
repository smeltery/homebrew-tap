# fugue

Incognito mode for AI coding agents: no-trace, sandboxed sessions.

```bash
brew install smeltery/tap/fugue
```

Stable installs build from the tagged source archive. For tip-of-tree:

```bash
brew install --HEAD smeltery/tap/fugue
```
