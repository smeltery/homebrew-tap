# Homebrew Tap for smeltery

[![License: PolyForm Shield 1.0.0](https://img.shields.io/badge/License-PolyForm%20Shield%201.0.0-blue.svg)](https://polyformproject.org/licenses/shield/1.0.0/)

This is the official Homebrew tap for smeltery tools.

## Installation

```bash
# Add the tap
brew tap smeltery/tap
```

### ConfigSync

```bash
brew install --cask smeltery/tap/configsync
```

### PRR

```bash
brew install --cask smeltery/tap/prr
```

### AWSW

```bash
brew install --cask smeltery/tap/awsw
```

## Available Casks

- **configsync** - Synchronize macOS application configurations across machines
- **prr** - AI-powered PR code review CLI
- **awsw** - Seamlessly switch between AWS SSO accounts and EKS contexts

## Contributing

This repository is automatically maintained. Cask updates are handled by GoReleaser in the respective tool repositories.

For issues with specific tools, please file issues in their respective repositories:
